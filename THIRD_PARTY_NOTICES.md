# Third-party UI resources

## shadcn/ui — MIT

`apps/web/src/components/ui/chart.tsx` adapts the ChartContainer/config/tooltip pattern from
[shadcn/ui Chart](https://ui.shadcn.com/docs/components/chart), with plain CSS styling for Radix Themes.
`ShopActivityChart` follows the [Area Chart examples](https://ui.shadcn.com/charts/area).
The registry reference used is `https://ui.shadcn.com/r/styles/new-york-v4/chart.json` (Recharts 3.8.0).

## Manrope — SIL Open Font License

`apps/web/src/fonts/manrope.ttf` and `apps/mobile/assets/manrope.ttf` are the variable Manrope font from Google Fonts.
Its original license is preserved alongside each font as `OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/manrope.

## Radix UI and Recharts

UI components use the installed `@radix-ui/themes` and Radix Primitives packages.
Area charts use `recharts`. Their original package licenses remain in their packages.
